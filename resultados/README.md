# Resultados

Esta pasta contém as cinco saídas finais geradas por `main.py` e validadas em
`EPSG:4326`:

- `amostra1_linhas_corrigidas.geojson`;
- `amostra2_linhas_corrigidas.geojson`;
- `amostra3_linhas_corrigidas.geojson`;
- `amostra4_linhas_corrigidas.geojson`;
- `amostra5_linhas_corrigidas.geojson`.

O sufixo `corrigidas` diferencia estas saídas de versões exploratórias que
podem estar abertas no QGIS localmente.
